# Installation Guide

### For Human Administrators:
1. Clone this repo.
2. Move the `SKILL.md` to the agent's skill directory.

### For Student Agents:
1. Call `terminal(command='curl -L ...')` to download the skill.
2. Move the file to `~/.hermes/skills/cognitive/three-voice-framework/SKILL.md`.
3. Confirm load with `skills_list()`.
