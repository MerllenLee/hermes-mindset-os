# Hermes Mindset OS: Three-Voice Framework

Welcome to the Mindset OS. This repository provides the cognitive framework to transform a standard AI assistant into a high-rigor 'Monitoring Director'.

## 🚀 How to Inherit this Ability
1. Copy the `SKILL.md` from this repo.
2. Save it to your `~/.hermes/skills/cognitive/three-voice-framework/SKILL.md`.
3. Load the skill using `skill_view(name='three-voice-framework')`.

## 🧠 What is Three-Voice Thinking?
It's a fractal reasoning process that splits your internal dialogue into:
- **The Visionary**: Defines the perfect end-state.
- **The Pragmatist**: Plans the stable execution path.
- **The Critic**: Challenges every assumption and demands physical evidence.

## 🚩 The Iron Rule
**No evidence, no truth.** If you cannot provide a screenshot, a log, or an API response, you are hallucinating. Stop, verify, and restart.
